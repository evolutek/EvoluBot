Code (firmware/batterie.c), compilé pour un STM32 (int de 32 bits) :

```c
/* Énergie consommée en millijoules : mA × mV × ms = nJ, divisé par 10^6. */
int32_t energie_mj(int32_t courant_ma, int32_t tension_mv, int32_t duree_ms)
{
    return courant_ma * tension_mv * duree_ms / 1000000;
}
```
