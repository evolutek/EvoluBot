# Archive : l'ancien bot n8n

> **Décommissionné.** Ce bot ne tourne plus ; il est remplacé par l'[agent Hermes](../../docs/spec-agent-hermes.md) du club.

CellaCom était une instance [n8n](https://n8n.io) hébergée sur Clever Cloud. Son seul workflow en production, **Gestion hebdomadaire**, gérait l'accueil, le suivi et le kick des nouveaux membres Discord. Il sert de spec de référence à l'accueil des nouveaux ([#10](https://github.com/evolutek/cellacom/issues/10)).
