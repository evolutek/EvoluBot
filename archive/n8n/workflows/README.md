# Workflows

Exported n8n workflow schemas for version control.

## How to Export

In n8n:
1. Open workflow
2. Click `...` menu → **Download**
3. Save JSON file here with descriptive name

## How to Import

In n8n:
1. Click **Add workflow** → **Import from file**
2. Select JSON file

## Naming Convention

```
<workflow-name>.json
```

Example: `discord-welcome-bot.json`

## Note

These are backup/reference copies. The source of truth is the live n8n instance.
